# Persimmon Cultivar Guide for Hungary

An interactive guide to growing persimmons (*Diospyros kaki*) in the Hungarian (Pannonian) climate.

**Live site:** https://mrgarris0n.github.io/persimmon/

## What's in it

- Cultivar groups suited to Hungarian gardens, including cold-hardy interspecific hybrids for Zone 5b/6a
- Sweetness potential (°Brix) of cultivars available from European nurseries
- Canopy height, pruning dimensions and foliage spread
- Winter minimum temperature limits per cultivar
- Rootstock selection for Hungarian soil conditions
- A region-based cultivar advisor

## Running locally

It's a single static page. Open `index.html` in a browser. Tailwind CSS, Chart.js and the Inter font load from CDNs, so you need an internet connection.

## Deployment

GitHub Pages serves the site from the root of the `main` branch. Pushing to `main` updates the site.
